## T05.b 实现证据

1. `trustedPeers` 是后端维护的持久配对记录，保存完整证书、角色、信任版本和配对时间，不从发现在线状态回填。
2. QUIC 双方出示本机持久证书。服务端验证 TLS CertificateVerify 后按完整证书精确匹配，回调携带 peer_id、角色、信任版本和本进程连接代次。
3. 未授权连接不启动 datagram reader；普通 stream 在应用入口拒绝。人工配对包的声明证书必须与 TLS 实际出示证书相同，配对后关闭旧连接并要求重新握手。
4. Mac 本机实际启动两个 QUIC endpoint 完成授权 stream 回环；另一个未知证书连接反复发送 datagram，接收回调保持为零。证书旋转、重复证书、错误角色和配对声明不一致均有负例。

验证：Mac 库回归 135/135；A10、A11、A12 自动化通过。测试没有调用真实系统注入或剪贴板。A43 仍未完成；Windows 仍 pending_environment，LOL optional_not_run。V2 协议未实现，因此旧 LAN 门禁未开启。
