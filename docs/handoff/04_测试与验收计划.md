# MyKVM Fork 测试与验收计划

版本：2.0 · Mac 优先开发 · 2026-09-07

## 1. 验收政策

**LOL 实机测试不是任何开发、合并或打包的硬性关卡。** Windows 不在身边或 CI 不可用时，继续完成 Mac 可执行开发与产物；未验证项独立列出。

本包只提供测试设计和初始状态，没有执行下面任何软件测试。文档生成校验不等于 MyKVM 编译/运行测试。

| 层级 | 在 Mac 开发阶段如何处理 |
|---|---|
| A：纯逻辑/假平台自动化 | 相应实现应运行；相关新失败必须修复 |
| M：Mac 构建、回环和本机 | 构建/回环优先；真实输入/权限/长时测试按可用性及用户授权 |
| W01：Windows 原生 CI | 可用就运行，缺环境单独待办，不阻塞其他任务 |
| W02-W06：Windows 桌面/双机 | 可选实机验证，不用 CI 成功冒充 |
| L01-L04：LOL | 全部可选，不在任务关键路径中 |

## 2. 证据状态

测试状态只能是 `not_run`、`pass`、`fail`、`pending_environment`、`optional_not_run` 或有理由的 `not_applicable`。自动化命令以真实退出码为准，不能把跳过测试标成通过。

每条证据记录：任务 ID、测试 ID、代码 SHA、OS/架构、命令、退出码、开始/结束时间、报告路径、结果摘要。截图只记录用户允许的测试场景，不采集私人代码或聊天作为截图证据。

Mock 测试只证明逻辑；Mac app 构建只证明 Mac 构建；Windows CI 的 lib tests 只证明其执行过的非交互代码。不互相替代。

## 3. Mac 上如何测试 Windows 相关设计

将 Windows 平台动作封装成接口。Mac 测试模拟 hotkey、capture、focus 的成功/失败和事件序列，验证路由策略、紧急返回、剪贴板调度与协议。

但 Windows 钩子真实生命周期、UAC/安全桌面、回报率、游戏焦点和原生安装器不能由 fake 实现证明。对应 Windows 代码仍要写完整，交给原生 CI 进行可用的编译检查；剩余运行效果放可选矩阵。

安全回环使用独立身份和配置、loopback 地址、FakeInjector。默认不在一台 Mac 上互相捕获真实键盘鼠标，以免抢走正在写代码的输入。

## 5. 故障注入场景

网络模拟覆盖：部分流数据到达、重连、重复/乱序 datagram、关键事件流中断、图片持续发送、连接成功但注入进度停滞。

进程模拟覆盖：路由 actor 不回应但紧急标志可用；权限中途失效；正常退出；peer boot ID 变化。真实强杀不能假定清理代码会执行：只记录观察到的残余行为，不把它写成自动释放保证。

输入模拟覆盖：Ctrl/Alt/Shift 按住、鼠标拖拽中断、组合键尚未释放、设置映射改变、重复 down、旧 up 晚到、同目标重复 GoRemote。

协议防护覆盖：未知 peer、凭据/证书改变、重放旧 session、过长帧、整数溢出、无授权图片流、畸形 UTF-8/图片、快速重复连接请求。运行本地模糊/语料测试时不向其他设备发送流量。

## 6. 资源测量

同一 Mac 比较：程序退出、托盘空闲、设置窗口打开、回环传输文本/图片。记录进程组 CPU、内存、子进程、采样频率和实际时长。对于 macOS 的单核百分比与 Windows 的总 CPU 百分比不要直接横比。

采样不能自己成为高占用源。正式 idle 采样建议每秒或更低频；性能分析工具的 overhead 单独说明。系统其它开发任务正在编译时不能拿它当纯软件空闲基线。

Windows 游戏可选对比：固定场景、画质、分辨率、帧率上限、后台任务，分别观察软件退出、托盘、本地游戏态、切回游戏。采集平均 FPS、1% low、P99 帧时间并重复多轮；2%～3% 可作内部报警参考，但要结合基线波动，不是统一合格线。

本轮没有 LOL 数据也可正常交付，报告为 `L01-L04 optional_not_run`。

## 7. 交付级别

- **代码预览交付**：实现和可用自动化/审查完成，真实产物与缺失环境证据分开。
- **Mac 构建产物**：必须有实际 ARM64 构建和文件；没有权限运行时，runtime 留待办。
- **Windows 构建产物**：必须有实际原生构建记录和 EXE/安装包；没有 runner 就明确未生成。
- **游戏兼容性结论**：只有运行过相应实际场景才可描述结果；它不是取得前三项的条件。

没有签名证书不要求购买；本地未公证产物标明用途和权限限制。公开发布、代码推送和安装覆盖遵循用户授权，不由“全部测试通过”自动触发。
