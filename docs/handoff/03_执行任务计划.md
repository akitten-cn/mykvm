# MyKVM Fork 执行任务计划

版本：2.0 · Mac 优先 · LOL 实机验证不阻塞开发、合并与打包

## 1. 任务执行语义

本计划是实施输入，不是已完成记录。每张任务卡定义输入、可修改范围、产出和验证。

任务依赖只指前置任务的代码/接口实现及主线程审查，不要求其中列出的可选 Windows/LOL 项已实测。`T23` 的 Windows runner 缺失不会使 `T25` 全局阻塞：构建脚本可以完成，Windows 二进制和 build 状态仍如实待办。

每次只实施一个原子任务。一个任务仍过大时，先在 taskboard 中拆成 `Txx.a/Txx.b`，更新依赖和边界，不能擅自扩大范围。每次审查真实 `git diff` 和命令输出后才能进入下一任务；不得以“已派给子代理”代替审查。

已有项目工作流要求逐任务人工确认时按该规则执行。本包不替换用户的全局 AGENTS，也不假装任意子代理一定存在。

## 2. 推荐顺序

```text
P0  T00 → T01 → T02/T03 → T21（CI文件可早做；执行环境不可用不等待）
P1  T04/T05 → T06 → T07 → T08
P2  T09 → T10 → T11；T12；T19（满足各自依赖再做）
P3  T13/T14 → T15 → T16；T17 → T18
P4  T20 → T22/T23；T24 → T25
```

斜杠表示逻辑上可独立，不表示默认同时改文件。特别是 `input.rs`、`lib.rs`、`quic_transport.rs`、配置模型同一时间只能有一个写入者。

**不要在 T11 后要求用户先运行 LOL 才允许做 T13。** Windows 实机效果记录为待验证，继续进行 Mac 可执行开发。

## 3. 每任务通用流程

```text
读取当前任务及前置证据
→ git status / diff，保护用户改动
→ 定位实际函数，核验设计适用性
→ 编写最小回归测试
→ 实现单个任务
→ 运行相应测试/构建
→ 主线程审查 diff、真实退出码和产出
→ 更新 taskboard、PROGRESS、测试报告
→ 按项目约定提交，再进入下一任务
```

保存日志要保留退出码，不能 `command | tee` 后只检查 tee 成功。不得 `git add .` 把环境记录/密钥一并提交，不得通过忽略全部 warning、删除测试、关闭 TLS 达到表面成功。

## 4. 完成与阻塞

真正阻塞相应任务：新引入的可复现编译/逻辑失败、协议关键接口未定、用户改动冲突、需要未授权的敏感系统变更、安全边界不成立。

不阻塞其他可做任务：没接第二台电脑、没启动 Windows/LOL、无 Windows CI 权限、没有签名证书、Mac 手动授权测试暂未完成。记录具体缺失证据后推进不依赖它的任务。

若所有剩余任务都依赖同一真实阻塞，停止并给出一个最小可执行解锁步骤；不是用“没有 LOL 实测”制造阻塞。

## 6. 原子任务卡

### T00 · 确认工作区、授权边界和源码来源

**前置**：无。**范围**：`工作区`；`项目 AGENTS.md`；`docs/handoff 或 handoff`。

**执行**：
1. 读取全部交接文档、项目 AGENTS 和实际可用 skill；保留用户未提交改动。
2. 核验 Git/Node/Rust/Xcode/架构与 GitHub 认证；未知项汇总一次，不编造型号和回报率。
3. 授权账户明确时创建/复用 fork；无认证先本地 clone 上游继续，不上传凭据/真实环境日志。

**验证**：文档/工作树/交付清单审查。见 `04` 与 `testcases.json`；实际平台项按可用性记录，LOL 不设关卡。

**产出**：环境记录；工作树/remote 记录；唯一任务执行入口。

**审查重点**：不能重置用户分支；不得修改全局 Codex 配置；文档优先确认 CR-001。

### T01 · 固定基线与复核源码映射

**前置**：T00。**范围**：`package.json`；`src-tauri/Cargo.toml`；`src-tauri/src/*`；`scripts/*`；`.github/workflows/*`。

**执行**：
1. 核验审查 SHA 的可达性并记录实际开发完整 SHA；已有仓库不强制回退。
2. 在同一 SHA 上复核函数、认证、队列、ReleaseAll、窗口、installer helper 和 updater。
3. 先进行 Mac 原版 lint/build/lib checks，保存已存在失败；Windows 基线能跑就跑，不能跑不挡住后续。

**验证**：M01。见 `04` 与 `testcases.json`；实际平台项按可用性记录，LOL 不设关卡。

**产出**：SOURCE_AUDIT；基线命令/退出码；旧建议→当前代码修正表。

**审查重点**：不重复实现异步 stream 和 release 无控制台；不得只读 README 当源码审查。

### T02 · 隔离 fork 身份及构建副作用

**前置**：T01。**范围**：`src-tauri/tauri*.json`；`src-tauri/src/main.rs`；`src-tauri/src/lib.rs`；`scripts/*`；`安装 hooks`；`前端 updater 调用`。

**执行**：
1. 确定测试版应用ID、配置/锁/日志/自启名。
2. 禁用上游自动更新和不需要的特权 helper 自动安装路径。
3. 审查 Mac sign/install；本地构建不得默认覆盖现有 app、改钥匙串或信任设置。

**验证**：A40, A42。见 `04` 与 `testcases.json`；实际平台项按可用性记录，LOL 不设关卡。

**产出**：隔离后的配置；安装/签名副作用清单；回滚说明。

**审查重点**：只改显示名不算身份隔离；保持原许可证；不能一刀切删掉 workspace 造成构建失败。

### T03 · 建立 Mac 可运行的核心测试接口

**前置**：T01。**范围**：`拟新增 routing/session/platform ports`；`src-tauri/src/lib.rs 测试接入`；`测试 fixtures`。

**执行**：
1. 创建 FakeClock/Capture/Injector/Transport；默认不读系统剪贴板、不发真实键盘事件。
2. 将必要纯逻辑从 OS 回调抽出；不强制整个项目拆多 crate。
3. 明确平台 cfg 与测试模式，不为让 Mac 编译通过而 stub 掉 Windows 功能。

**验证**：A28, M05。见 `04` 与 `testcases.json`；实际平台项按可用性记录，LOL 不设关卡。

**产出**：测试端口与固定 fixtures；不影响真实桌面的测试入口。

**审查重点**：测试不能抢 Codex 输入焦点；生产代码不得默认接受 test token。

### T04 · 实现路由状态机和本地应急通道

**前置**：T03。**范围**：`拟新增 routing.rs`；`input.rs`；`lib.rs 路由入口`。

**执行**：
1. 实现 GoRemote/GoLocal/SetGameMode 与五种路由态。
2. 新增本地原子覆盖通道，取消请求后拒绝晚 ACK。
3. 普通切换等键松开；应急返回不等远程、不被主 actor 阻塞。

**验证**：A01, A02, A03, A04, A07。见 `04` 与 `testcases.json`；实际平台项按可用性记录，LOL 不设关卡。

**产出**：状态机代码；转移表对应单测。

**审查重点**：不要用 toggle 代替指定目标；不得让返回排在图片任务后。

### T05 · 复核并绑定已配对连接身份

**前置**：T02, T03。**范围**：`lib.rs 配对/授权路径`；`quic_transport.rs 连接上下文`；`拟新增 authenticated peer 类型`。

**执行**：
1. 证明双向授权在哪里完成；传输 with_no_client_auth 不冒充 mTLS。
2. 仅从持久配对信任获得证书/凭据；授权上下文绑定具体连接和角色。
3. 配对层不足时实现最小补充并写 ADR；真实LAN注入在验证前保持禁用，其他模拟任务可继续。

**验证**：A10, A11, A12, A43。见 `04` 与 `testcases.json`；实际平台项按可用性记录，LOL 不设关卡。

**产出**：授权调用链；正反授权测试；必要的安全 ADR。

**审查重点**：发现广播不得直接成为信任；不能只验 SocketAddr 或网络自报 peer_id。

### T06 · 实现 V2 分帧、会话握手与版本协商

**前置**：T05。**范围**：`拟新增 protocol_v2.rs`；`shared_input.rs`；`quic_transport.rs`。

**执行**：
1. 实现 Prepare/Ready/Commit/ACK/End 及 boot/session 标识。
2. control/input 持久流采用有界逐帧解析，不等整个流 EOF。
3. 限制长度/版本/角色；取消和超时不吞本机输入；不兼容明确拒绝。

**验证**：A13, A14, A15, A16, A17。见 `04` 与 `testcases.json`；实际平台项按可用性记录，LOL 不设关卡。

**产出**：协议结构；帧语料/兼容拒绝测试；协议版本记录。

**审查重点**：协议是拟新增；不继续把内部 ReleaseAll 当线上已存在的消息。

### T07 · 实现接收账本、健康与真实释放

**前置**：T04, T06。**范围**：`拟新增 session.rs`；`pressed_state.rs`；`input.rs 接收/注入`。

**执行**：
1. 跟踪已提交的目标键/按钮、冻结映射和重复/引用语义。
2. 正常结束、有效超时、权限变化走真实 release 路径；健康检测与图片隔离。
3. 结束的 session 不复活；清理失败可见；如实描述进程强杀残余风险。

**验证**：A18, A19, A20, A21。见 `04` 与 `testcases.json`；实际平台项按可用性记录，LOL 不设关卡。

**产出**：账本和租约逻辑；释放测试；崩溃边界说明。

**审查重点**：仅清集合不算释放；OS调用返回不等于应用动作执行成功。

### T08 · 改造有界调度和鼠标/按钮顺序

**验证**：A22, A23, A24, A25, A26, A27, A29。见 `04` 与 `testcases.json`；实际平台项按可用性记录，LOL 不设关卡。

**审查重点**：不能丢相对位移；QUIC流共享拥塞不等于零竞争；不能每移动 spawn task。

## 7. 多代理使用约定

主线程负责架构、授权边界、任务计划、接口冻结、真实 diff 和证据审查。实现代理只接一个任务；测试代理只使用已定义测试策略，不自行扩大产品范围。

如果项目里实际可用 `$sol-multi-agent-development`，先读取对应 SKILL，再按其约定委派；没有该 skill 就单线程执行。只通过项目级 AGENTS/配置引用，不修改 `~/.codex/AGENTS.md` 或全局模型配置。

每次委派包含：当前已批准计划、唯一任务ID、必读文件、允许改动范围、禁止项、测试命令、退出条件和升级路径。子代理不能自行切换协议或复制其他许可证的实现。

## 8. 计划调整

源码已包含某改造时，任务改为验证、修边界和回归，不重复造实现。发现新的高风险问题时记 ADR，说明证据、最小改动与影响的任务。不要因为看到一个不同框架就重新选型。

本包冻结的是需求与行为契约，不冻结每个私有函数名称。所有 API 以当前实际依赖版本和本地编译结果为准。
